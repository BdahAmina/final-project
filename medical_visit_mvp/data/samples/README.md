# Fictional samples

Everything here is invented for development, demonstration and evaluation. No real person is described.

- `visit_transcript.txt` — a short fictional visit in the `רופא:` / `מטופל:` paste format.
- `assistant_cases.json` — fictional cases (transcript, doctor-reviewed facts, doctor-entered context, questions and
  the safeguard behaviour expected) used by `data/evaluation/evaluate_assistant.py`.
