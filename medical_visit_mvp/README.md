# סיכום ביקור רפואי — אב־טיפוס לימודי

הקלטה מהמיקרופון או העלאת קובץ → תמלול מקומי → שיוך דוברים ותיקון התמלול → השחרת פרטים מזהים ובדיקה ידנית →
סיכום רפואי מובנה → בדיקה וחתימה אלקטרונית של הרופא → סיכום למטופל → ייצוא.
לצד התהליך: **עוזר קליני לרופא** — כלי עזר לרופא בלבד, שמחזיר טיוטות מבוססות מקורות לבדיקה, נפרדות מהעובדות שנאמרו בביקור.

> אב־טיפוס לימודי שנבחן עם **מטופלים בדויים**. אינו מכשיר רפואי מאושר, ולא נטענת עמידה ב־HIPAA או ב־21 CFR Part 11
> (ראו `data/documents/COMPLIANCE_MATRIX.md`). כל העיבוד מקומי: faster-whisper לתמלול ו־Ollama למודל השפה. שום תוכן אינו נשלח לשירות ענן.

## התקנה והפעלה ב־Windows PowerShell

```powershell
cd C:\Users\amina\Downloads\Medical_Visit_MVP
.\venv\Scripts\python.exe -m pip install -r .\medical_visit_mvp\requirements.txt
cd .\medical_visit_mvp
# פעם אחת: מודל השפה המקומי (דורש התקנת Ollama מ־https://ollama.com)
ollama pull qwen3:8b
# פעם אחת: מנהל/ת המערכת הראשון/ה (הסיסמה מוקלדת בהנחיה מוסתרת)
..\venv\Scripts\python.exe -m backend.manage create-admin --username admin --display "שם מלא"
# הפעלת המסך (http://localhost:8501)
..\venv\Scripts\python.exe -m streamlit run app.py
```

אפשר גם `Start.bat`, או `deployment\run_ui.ps1` / `deployment\run_api.ps1` (מריצים מיגרציות ומאזינים ל־127.0.0.1 בלבד).
אין צורך להפעיל את ה־venv; הפקודות משתמשות בו ישירות. אם בכל זאת מפעילים:
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned; ..\venv\Scripts\Activate.ps1`.

## תפקידים

| תפקיד | מה מותר |
|---|---|
| מנהל/ת מערכת | יצירת משתמשים וקביעת תפקידים, השבתה, איפוס סיסמה, שיוך רופא–מטופל, יומן ביקורת (סינון, דפדוף, ייצוא, בדיקת שלמות). **ללא גישה לתוכן קליני.** |
| רופא/ה | ביקורים של מטופלים המשויכים אליו/ה: תמלול, בדיקה, טיוטות, עוזר קליני, תוכנית, חתימה, ייצוא. |
| מטופל/ת | רק סיכומים שלו/ה שנחתמו, כולל תוכנית שהרופא/ה אישר/ה; הורדה כ־TXT/PDF/JSON. |

אין הרשמה עצמית. המנהל/ת יוצר/ת חשבונות עם סיסמה זמנית, שחובה להחליף בכניסה הראשונה. סשן מסתיים אחרי 15 דקות ללא פעילות
או 8 שעות. חמש כניסות שגויות נועלות את החשבון ל־15 דקות.

## תהליך ביקור (רופא/ה)

1. בסרגל הצד: ביקור חדש למטופל/ת משויך/ת, עם אישור הסכמה להקלטה.
2. לשונית **תמלול וטיוטות**: הקלטה, העלאה או הדבקה (`רופא:` / `מטופל:`); בדיקת התמלול ושיוך הדוברים; השחרה ובדיקתה;
   חילוץ ממצאים וסיכום למטופל במודל המקומי, ועריכתם.
3. לשונית **עוזר קליני לרופא**: הזנת נתוני מטופל לבדיקות בטיחות (גיל, אלרגיות, תרופות, הריון, כליות, כבד — "לא ידוע" נשאר לא ידוע),
   ושאלות על המטופל/ת. כל תשובה היא טיוטה עם מקורות מצוטטים; כל הצעה ניתנת לקבלה, עריכה או דחייה.
4. לשונית **תוכנית, חתימה והורדה**: תוכנית הרופא (נפרדת מהעובדות שנאמרו), חתימה אלקטרונית (שם משתמש + סיסמה, שם, מועד UTC, משמעות),
   והורדה. כל עריכה אחרי החתימה יוצרת גרסה חדשה ומבטלת את האישור.

## מגבלות עיקריות

- אין אימות דו־שלבי, אין TLS בתוך האפליקציה ואין הצפנה של קובצי SQLite.
- ההשחרה היא פסבדונימיזציה עם בדיקה ידנית, לא דה־אידנטיפיקציה.
- באוסף המקורות יש רק תוויות תרופה של ה־FDA (ארה״ב); מקור הנחיות ה־CDC חסום מרשת זו. אין הנחיות קליניות למצבים.
- הפרדת דוברים אוטומטית דורשת pyannote.audio ו־HF_TOKEN; בלעדיה משייכים דוברים בטבלה.
- הקלטה עד 24MB ועשר דקות; אין תמלול רציף בזמן הדיבור.
