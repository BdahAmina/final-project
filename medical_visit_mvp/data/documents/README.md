# Project documents

- `IMPLEMENTATION_STATUS.md` — requirement-by-requirement status with files and verification evidence.
- `DATABASE.md` — database location, tables, migrations and how to inspect them.
- `CLINICAL_ASSISTANT.md` — the doctor-only clinical support agent: architecture, boundaries, risks, evaluation.
- `COMPLIANCE_MATRIX.md` — HIPAA and 21 CFR Part 11 compliance statement and provision-by-provision matrix.
- `compliance/` — security policies, electronic-signature policy, risk analysis, validation plan (IQ/OQ/PQ) and the
  Hebrew compliance text for the proposal (`COMPLIANCE_SUMMARY_HE.md`). Validation reports go to `data/validation/`.
- `PROPOSAL_UPDATE.md` — changed scope added to the project proposal (also merged into the updated .docx copy).

Files placed here are documentation only; nothing in this folder is loaded into a model.
